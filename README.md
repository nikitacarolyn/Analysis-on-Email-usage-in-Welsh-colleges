# Analysis-on-Email-usage-in-Welsh-colleges
An end-to-end data pipeline and ETL process using Tableau Prep and Tableau to optimise and analyse workforce productivity logs.

### 📌 Project Objective
This project involved engineering an end-to-end data pipeline to analyse communication logs from Welsh colleges. The primary focus was optimising organisational workflow through data extraction, cleaning, transformation, and structural modeling.

### ⚙️ Data Engineering Architecture
- **ETL Implementation:** Utilised Tableau Prep to structurally ingest, clean, and map unstructured log data.
- **Process Optimisation:** Isolated operational anomalies within communication data streams, calculating a 70.87% non-work-related time allocation.
- **Data Visualisation:** Modeled high-level internal productivity dashboards in Tableau to present actionable workforce insights to stakeholders.

### 🛠️ Tech Toolkit
- **Data Engineering:** Tableau Prep (ETL processing)
- **Business Intelligence:** Tableau Desktop (Analytics Dashboards)
